# Jeu de tir spatial 3D

## Concept
- Jeu type **aim shooter** en **3D**, contrôlé via un **avion/vaisseau spatial**.  
- Les cibles sont des **formes qui apparaissent aléatoirement** et se déplacent dans l’espace.  
- Le joueur doit viser et tirer pour **gagner des points** avant la fin du temps imparti.  

---

## Fonctionnalités principales
- **Système de score et chrono** pour mesurer performance et rapidité.  
- **Plusieurs niveaux de difficulté** pour adapter le challenge.  
- **Caméra dynamique** qui suit le vaisseau dans l’espace.  
- **Différents modes de tirs** pour varier le gameplay.  
- **Mouvements aléatoires des cibles** pour rendre le jeu imprévisible et stimulant.  

---

## Idées pour enrichir le gameplay
- Multiples types de cibles avec comportements variés.  
- Modes de jeu différents (classique, survie, challenges).  
- Power-ups ou bonus liés aux tirs.  
- Évolution de la difficulté selon la progression du joueur.
